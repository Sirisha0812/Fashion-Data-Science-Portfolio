# Retail Demand Forecasting for Apparel

## Problem Statement

Forecast demand for apparel items to optimize inventory and reduce overstock/understock, using historical sales data and external factors.

## Dataset

Kaggle's Retail Store Inventory Forecasting dataset with 73,000 rows of daily sales data, combined with promotions, holidays, and weather data.

## Methods

- Engineer features (day-of-week, holidays, promotions, weather)
- Build time-series models (ARIMA, Prophet, LSTM)
- Compare with gradient boosting methods (XGBoost)
- Evaluate forecasts using MAPE and RMSE
- Perform scenario analysis for different promotional strategies

## Expected Results

- MAPE of 8% on validation data
- Reduce stockouts by 30% and overstock by 20%
- Enable effective seasonal peak planning

## Tech Stack

Python, Pandas, Scikit-learn, XGBoost, Prophet or Statsmodels, Matplotlib, Jupyter Notebook

## Impact

Improves inventory management decisions, reduces waste, and increases profitability through data-driven demand forecasting.
