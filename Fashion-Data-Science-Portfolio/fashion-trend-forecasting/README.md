# Fashion Trend Forecasting with Social Media and Sales Data

## Problem Statement

Predict upcoming fashion trends by analyzing historical sales data and social media signals (images, hashtags) to help designers and retailers plan collections and inventory.

## Dataset

Kaggle's Fashion Trend dataset with preferences, trends, and sales metrics over three years, combined with Instagram image data and hashtags.

## Methods

- Preprocess and clean sales and social media data
- Extract visual features from images using CNNs (ResNet/EfficientNet)
- Perform text mining on hashtags and captions
- Cluster images and hashtags to identify emerging trends
- Use time-series models (ARIMA, LSTM) to forecast trend popularity
- Validate using back-testing and cross-validation

## Expected Results

- Forecast top trending categories with >80% accuracy
- Identify color and pattern trends one season ahead
- Reduce overstock by 15%

## Tech Stack

Python, Pandas, NumPy, TensorFlow/PyTorch, Scikit-learn, Matplotlib, Jupyter Notebook

## Impact

Provides actionable insights for fashion brands, reducing environmental waste by aligning production with demand and enabling data-driven design decisions.
